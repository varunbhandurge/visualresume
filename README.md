## 🏛️ Linear / Stripe Executive Dark Aesthetic

- **Color Palette:** Deep Obsidian (`#07080A`), translucent dark cards (`bg-white/[0.02]`), ultra-fine hairline borders (`border-white/[0.08]`), and warm champagne gold (`#F59E0B`) or crisp indigo accents.
