## ⚡ Dynamic Executive UI/UX Design

An interactive, high-energy executive product showcase built for **Varun Bhandurge**, deployable seamlessly on **Vercel**.

- **Atmospheric Ambient Glow:** Layered violet, cyan, and emerald radial lighting over deep stealth obsidian (`#08090C`).
- **Interactive Live Telemetry & Prototype Deck:**
  - Real-time trading latency and daemon status for the live SaaS deployment **MaximusOne**.
  - Interactive BFSI impact statistics (`₹10 Cr+`, `95%+`, `40%`).
  - Interactive AI Prototype Sandbox with instant syntax-highlighted payload previews and copy-to-clipboard.
- **Interactive Institutional Delivery Ledger:** Clickable BFSI partner strip (**ICICI Bank**, **HDFC ERGO**, **ICICI Prudential**, **ABSLI**, **Reliance ADAG**) displaying verified project scopes, impact metrics, and technology stacks.
- **The 4-Stage Chronological Delivery Engine:** Visual pipeline covering Commercial Structuring (`AM`) &rarr; Elicitation & AI Prototyping (`Lead BA · ECBA™`) &rarr; Full-SDLC Agile Execution (`PM · CSM®`) &rarr; Customer Onboarding & Renewals (`AM`).
- **Rich Bento Systems Showcase:** Featuring live web app frames, telemetry drawers, multi-agent pipelines, document OCR engines, and automated job search agents.
- **Slide-Over Recruiter Dossier:** Complete keyword matrix, verified credentials, and instant one-click resume download.

## 🏗️ Architecture & Component Directory

```
src/
├── app/
│   ├── globals.css                       # Atmospheric ambient glows, glassmorphism, scrollbars
│   ├── layout.tsx                        # SEO metadata, OpenGraph, viewport configuration
│   └── page.tsx                          # Assembles dynamic interactive sections & drawer state
├── components/
│   ├── LinearNavbar.tsx                  # Floating glassmorphic navigation pill with status indicator
│   ├── DynamicHeroShowcase.tsx           # High-impact gradient headline + 3-tab live telemetry deck
│   ├── InteractiveBFSIStrip.tsx          # Clickable BFSI partner ledger with project scopes
│   ├── ConnectedEngineSequence.tsx       # 4-stage connected delivery engine (AM → BA → PM → AM)
│   ├── BentoSystemsShowcase.tsx          # Rich bento cards for MaximusOne, BASwarm, BillVault, etc.
│   ├── SlideOverDossier.tsx              # Slide-over recruiter drawer with keyword taxonomy
│   └── LinearFooter.tsx                  # Modern footer with direct contact links and PDF download
└── public/
    ├── resume.pdf                        # Downloadable traditional PDF resume
    └── icon.svg                          # High-contrast monogram favicon
```
